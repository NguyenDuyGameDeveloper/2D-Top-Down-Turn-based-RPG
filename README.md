# 2D-Topdown-Turnbased-RPG

A 2D top-down turn-based RPG developed with Unity and C#,
designed for mobile platforms.

## 🎮 Play


## Features

- Grid-based turn-based combat
- Speed-based enemy actions
- Active and passive skills
- Character stats and equipment
- Inventory system
- Item quality and item merge system
- Stage-based progression
- Quest / mission system
- Enemy AI
- Local save / load system
- Mobile-oriented controls and UI

## Technical Highlights

- Grid-based movement and coordinate system
- Turn / action sequencing system
- Unity Input System for keyboard and mobile input
- ScriptableObject-based game data
- Modular character and enemy systems
- State Machine architecture

## Technologies

* Unity
* C#
* Aseprite
* Git & GitHub
* PlayFab

## Project Information

**Role:** Unity Developer, Designer  
**Engine:** Unity 6 (6000.0.62f1)  
**Language:** C#  
**Platform:** Android / WebGL / Windows
**Status:** In Development

## Project

This project is being developed as a mobile-focused
turn-based RPG with the intention of becoming a commercial game.

The project focuses on building a scalable gameplay foundation,
including grid-based movement, turn-based combat, character
progression, equipment, inventory, quests, and stage progression.

Online services such as PlayFab are planned for future
features including cloud save, leaderboard, and other
online functionality.
